# Extensão Offer 0.3.6

Extraia o ZIP e carregue a pasta em chrome://extensions ou edge://extensions, usando Modo do desenvolvedor → Carregar sem compactação. Para atualizar, substitua os arquivos na pasta instalada, recarregue a extensão e atualize o painel.

No Offer → Configurações → Conexões, clique Conectar extensão. Valide uma loja usando um produto real. A extensão usa as contas já conectadas e os controles visíveis das ferramentas afiliadas; não faz login, não resolve verificações e não publica no WhatsApp.

A busca contínua requer navegador aberto e aplicativo local ativo. Lojas sem conta ou com leitura inconclusiva permanecem indisponíveis. Abas criadas pela extensão são fechadas no sucesso e preservadas quando precisam de atenção.

O botão do navegador mantém a captura pontual de produtos e vitrines do Mercado Livre como alternativa. Confirme a importação no painel; a captura não aprova envios.
